# 📊 Retail Sales Descriptive Statistics

## 📌 Project Overview

This project performs **Descriptive Statistical Analysis** on retail sales data to understand the distribution, variation, relationships, and unusual observations within the dataset.

The analysis was performed using **Microsoft Excel** and focuses on statistical measures, outlier detection, correlation analysis, and data visualization.

---

## 🎯 Objectives

* Calculate and analyze descriptive statistical measures
* Understand the central tendency of sales data
* Analyze data dispersion and variability
* Calculate quartiles and percentiles
* Identify potential outliers
* Analyze skewness
* Examine relationships between sales and profit
* Generate visualizations to support statistical findings

---

## 🛠️ Tools Used

* Microsoft Excel
* Statistical Analysis
* Data Visualization

---

## 📂 Dataset

**File:** `Superstore_Sales_Descriptive_Statistics.xlsx`

The workbook contains the following sheets:

* `SalesData`
* `Statistical_Analysis`
* `Outlier_Analysis`
* `Visualizations`

## 📊 Statistical Analysis Performed

The project includes the following statistical measures:

* Mean
* Median
* Mode
* Variance
* Standard Deviation
* Minimum
* Maximum
* Quartiles
* Interquartile Range (IQR)
* Percentiles
* Skewness
* Outlier Analysis
* Correlation Analysis

---

## 🔍 Outlier Analysis

Outliers were analyzed using the **Interquartile Range (IQR) method**.

The analysis includes:

* Q1
* Q3
* IQR
* Lower Bound
* Upper Bound
* Outlier Count
* Outlier Percentage

---

## 🔗 Correlation Analysis

The project also analyzes the relationship between **Sales and Profit** using correlation analysis.

The result helps understand the strength and direction of the relationship between the two variables.
